Raw Unicode CLDR v48 Ethiopic calendar data, vendored verbatim.

Source: https://github.com/unicode-org/cldr-json  (tag 48.0.0)
        cldr-json/cldr-cal-ethiopic-full/main/<locale>/ca-ethiopic.json

These are the official Unicode CLDR `cldr-cal-ethiopic-full` files, committed
unmodified, for the same CLDR "modern" coverage base languages as the sibling
`dates/` directory (101 locales). `codegen` reads them to produce
src/cldr/alt_calendars.bin. Do not hand-edit; to refresh, re-download from the
same upstream path at the pinned CLDR version.

13 months and two eras (0 = Amete Alem, 1 = Amete Mihret). The BCP-47 calendar
`ethioaa` is this same data counted from era 0.
